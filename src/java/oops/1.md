# what is cloneable?
In Java, **`Cloneable`** is a marker interface used to indicate that a class allows its objects to be cloned field-by-field using the `Object.clone()` method.

**How It Works**

* **Marker Interface:** It contains no methods or constants. Its sole purpose is to act as a flag or permission check for the Java runtime.
* **Interaction with `Object.clone()`:** The `clone()` method is defined in `java.lang.Object` as `protected`. When a class calls `super.clone()`, the JVM checks whether the class implements `Cloneable`.
* **`CloneNotSupportedException`:** If a class attempts to call `clone()` without implementing `Cloneable`, the JVM throws a `CloneNotSupportedException`.

---

**Basic Implementation**

```java
public class Person implements Cloneable {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // Override clone() to make it public
    @Override
    public Object clone() throws CloneNotSupportedException {
        return super.clone();
    }
}

```

---

**Shallow vs. Deep Copy**

* **Shallow Copy (Default):** `super.clone()` copies primitive fields by value and reference fields by reference. Both the original and cloned object will point to the same referenced sub-objects in memory.
* **Deep Copy:** If your class contains mutable reference types (like arrays, lists, or custom objects), you must manually clone those inner objects inside your overridden `clone()` method to prevent side effects.

---

**Common Drawbacks & Alternatives**

The `Cloneable` architecture is widely considered flawed in modern Java design because:

* `Cloneable` doesn't actually declare a public `clone()` method—you still have to override `Object.clone()`.
* It bypasses standard constructors, making state validation tricky.

**Preferred Alternatives:**

* **Copy Constructor:** `public Person(Person other) { ... }`
* **Static Factory Method:** `public static Person newInstance(Person other) { ... }`
* **Serialization / Libraries:** Using libraries like Jackson or Apache Commons to perform deep copies.
