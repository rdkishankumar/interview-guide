You now have **two separate issues**, both easy to fix:

1. Port `8080` is already occupied by your RPM-installed Jenkins.
2. The first failed `docker run` still created a container named `jenkins`.

If your goal is to run **Jenkins through Docker**, do this in order.

### 1. Check the existing container

```bash
docker ps -a
```

You'll probably see `jenkins` with a status like `Created`.

### 2. Remove the failed Jenkins container

```bash
docker rm -f jenkins
```

Verify:

```bash
docker ps -a
```

### 3. Find what's using port 8080

```bash
sudo ss -ltnp | grep :8080
```

Your previously installed Jenkins is likely using it.

Check:

```bash
sudo systemctl status jenkins
```

### 4. Stop the old Jenkins

Because you want Docker Jenkins to own port `8080`:

```bash
sudo systemctl stop jenkins
sudo systemctl disable jenkins
```

Confirm 8080 is free:

```bash
sudo ss -ltnp | grep :8080
```

If there is **no output**, that's good.

### 5. Start Jenkins in Docker

Now run:

```bash
docker run -d \
  --name jenkins \
  --restart unless-stopped \
  -p 8080:8080 \
  -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  jenkins/jenkins:lts-jdk21
```

You should get a long container ID without an error.

### 6. Verify Jenkins

```bash
docker ps
```

You should see something like:

```text
CONTAINER ID   IMAGE                       PORTS
abc123...      jenkins/jenkins:lts-jdk21   0.0.0.0:8080->8080/tcp
```

Check Jenkins logs:

```bash
docker logs -f jenkins
```

When you see that Jenkins is ready, press `Ctrl+C`. That exits log viewing, **not** the container.

### 7. Get your new Jenkins password

Important: this Docker Jenkins has its **own Jenkins home**, so it may have a different initial password from your previous installation.

```bash
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword
```

Then open:

[Jenkins on your EC2 instance](http://51.20.8.71:8080?utm_source=chatgpt.com)

### Option 2: Keep both Jenkins installations

If you want to keep your existing Jenkins on `8080`, run Docker Jenkins on another host port, such as `8081`:

```bash
docker rm jenkins
```

Then:

```bash
docker run -d \
  --name jenkins \
  --restart unless-stopped \
  -p 8081:8080 \
  -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  jenkins/jenkins:lts-jdk21
```

Then access Docker Jenkins at:

```text
http://51.20.8.71:8081
```

Remember that if you use `8081`, your EC2 Security Group also needs to allow inbound TCP **8081** from your IP.

For your setup, I'd use **Option 1** so you don't have two Jenkins installations competing with each other.
